# Exercițiu Atestat C

Acesta este un program simplu scris în C care demonstrează lucrul cu șiruri de caractere, pointeri și funcții.

## Descriere
Programul definește un cuvânt predefinit ("buna") și îi calculează automat lungimea. Ulterior, apelează o funcție care afișează cuvântul inițial, urmat de un număr de puncte egal cu lungimea sa (rezultatul afișat va fi `buna....`).
